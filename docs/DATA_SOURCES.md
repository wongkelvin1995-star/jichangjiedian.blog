# 数据来源与处理说明

本文说明站内每一类数据**从哪里来、怎么分级、哪些不能当真**。它对应总指令第 11–14 节（导入既有资料、四种证据状态、已知冲突、套餐要求），也是交付物 G（机场资料及套餐数据）和 O（数据真实性与未核验问题）的依据。

> 配套文件：
> - `docs/DATA_SOURCES_TABLE.md`：品牌 × 来源的完整对照表（由 `npm run report:sources` 从 `src/data` 自动生成，不是手写）。
> - `docs/OPEN_ISSUES.md`：尚未核验的问题、缺失文件、没有执行的外部操作。
> - `docs/SEO_PAGES.md`：全站 73 个页面的清单（由 `npm run report:pages` 从 `dist/` 自动生成）。

## 2. 四级证据与字段级来源

| 等级 | 名称 | 含义 | 站内如何使用 |
| :---: | --- | --- | --- |
| **A** | 本站实测 | 本站自己测的，包含时间、环境、原始截图或日志 | 只有灵动云的 3 项记录（网页测速、YouTube 观察、节点在线快照）标为 A，因为是站长自己的测试。**但原始截图没有挂载，所以它们都是“未核验”**（`isVerified: false`），也不进入分时段统计（见第 6 节） |
| **B** | 服务商公开资料 | 来自能识别为服务商的公开说明或后台截图 | 目前没有。页面存档没有抓取日期，不能确认是服务商当时的公开说明 |
| **C** | 第三方历史参考 | 第三方文章、页面存档、历史图，非本站测试 | 套餐价格、地区、协议等字段的主要来源 |
| **D** | 待核验或资料冲突 | 不能当作确定数据 | 汇编资料、演示站、同名主体、来源冲突的字段；只作线索展示 |

**“等级”和“已核验”是两回事。** 等级（A–D）说明来源是什么；“已核验”（`isVerified`）只在存在可核查的原始证据时才能为 `true`。所以灵动云的页面会同时出现“A 本站实测”和“原图待补充，暂未标记为已核验”两个标记，这不是矛盾，而是如实说明：测试是站长做的，但本站还拿不出原图。

**字段级，而不是品牌级。** 一家品牌不会因为“有来源”就整体变成“已核验”。每个有判断价值的字段（价格、流量、地区、线路、协议、客户端、流媒体声明、AI 声明……）都是一个 `Claim<T>`：

```ts
interface Claim<T> {
  value: T | null;        // null = 资料没有提供 / 未知。不是 0，也不是“无”
  grade: 'A' | 'B' | 'C' | 'D';
  sourceIds: string[];    // 指向来源登记表（src/data/source-registry.ts）
  recordedAt?: string | null;
  note?: string;
  conflict?: boolean;     // 与其他来源冲突：不参与精确排序，不能当确定数据
}
```

几条硬规则（`npm run validate:brands` / `validate:evidence` 每次都会检查）：

- **空值不自动变 0。** 未知价格、未知流量、未测得的丢包率都是 `null`，页面显示“—”或“未提供”。
- **没有原始证据的记录不得 `isVerified: true`。**
- **没有日期的记录，时间窗口一定是 `unknown`。** 来源自述“晚高峰测的”只能放进 `claimedWindow`，不进入任何统计。
- **A 级字段必须引用本站来源。**
- **品牌身份不自动合并。**（第 5 节）
- **推广链接不是证据。** 它们不出现在搜索索引、CSV、JSON-LD 里，也不参与任何数据计算。

几个容易误解的点：

- **“页面自述日期”不是本站核验日期。** 例如不少机场观察站的页面写着“2026-10-16”，那是评测站自己的说法；站内只把它显示为“页面标注 2026-10-16”，不会写成“本站于该日核验”。
- **`receivedAt`（2026-10-27）是你提供资料的日子，不是页面抓取日。** 没有任何页面存档能证明抓取日期，所以全站不使用“最后更新价格”这类措辞来暗示资料新鲜。
- **上传编号只用来追溯文件，不参与排序。** 品牌展示顺序是你指定的固定编辑顺序（`displayRank`），不是排名，不按任何评分变化。

## 4. 汇编资料（MD）为什么只作线索

34 份单品牌 MD 和 2 份综合库是二次整理的汇编资料。逐份对照页面存档之后发现它们**不适合当事实用**，所以默认 D 级：

- **与页面存档冲突。** U1S1 和二猫云：汇编资料的套餐表与各自页面存档不是同一套（流量档位、价格、名称均不同）。
- **同一套数字出现在不同品牌上。** 例如全球云页面存档的套餐价位与流量档位（¥20/120GB、¥40/300GB、¥100/700GB、¥180/1500GB、¥600/500GB）与暮光加速页面存档**相同**——可能是共用了同一套套餐模板，本站不据此判断两者的关系，只在品牌档案里如实记录。宇宙云页面里那套“星云年付小包 / 行星基础版 / 恒星标准版 / 星系专业版 / 寰宇旗舰版”的命名，同样出现在汇编资料里的**灵动云**条目中，但灵动云自己的页面存档用的是另一套名称。
- **演示站被写成了真实品牌。** 闪电云的页面标题与页脚都写“静态演示站点”，汇编资料却给出了一套完整套餐，而且与演示页上的价格并不一致。本站把所有字段降为待核验，只保留线索。
- **同名主体被当作机场。** 环球云的页面存档是一家云计算 / CDN 公司，汇编资料却给了四个机场套餐，这些套餐在页面存档里找不到依据，数字还与“神行加速”的价格表相同。
- **模板痕迹。** 例如 U1S1 页脚写“2026-2029”版权年份、宇宙云页面仍使用已更名的“Google Bard”，说明页面文字可能沿用旧模板，本站不据此判断上线时间或服务内容。

处理原则：**能用页面存档的字段，用页面存档（C）；只有汇编资料能提供的数字，保留但标 D，价格表里标“仅见于汇编资料”，不参与精确排序。** 全部 300 条报价的状态分布：

| 报价状态 | 条数 | 含义 |
| --- | ---: | --- |
| 有页面来源（`sourced`） | 249 | 页面存档支持，且未发现冲突 |
| 资料冲突（`conflict`） | 34 | 多个来源不一致，**不参与精确排序** |
| 仅见于汇编资料（`compiled-only`） | 15 | 待核验 |
| 咨询报价（`consult`） | 2 | 没有公开价格 |

另外 298 条有标价、292 条能确定月流量或总流量；其余留空，而不是估算。

## 7. 数据如何流到页面

```
src/data/            ← 唯一的数据源（品牌、套餐、地区、线路、来源、测试记录、证据）
   ├─ 首页地图 / 地区面板 / 筛选      同一份 MAP_POINTS 与品牌地区声明
   ├─ /airports/ 目录与品牌页
   ├─ /plans/ 套餐对比                 300 条报价，由脚本筛选，无 JS 时是完整表格
   ├─ /regions/、/routes/
   ├─ /test-records/、/time-tests/、/data/test-records.csv
   ├─ /search-index.json               站内搜索索引（构建时生成，不含推广链接）
   └─ sitemap.xml 与 JSON-LD            只含规范、可索引的页面
```

地图、目录、套餐页和地区页读取的是**同一份数据**，没有任何页面单独写死数字。首页地图上的“航线”是地区关系的示意，页面上有明确文字：“航线为地区关系示意，非实际物理路由”。

## 9. 更新数据时请遵守

1. 新的来源先登记到 `src/data/source-registry.ts`，再在字段里引用它的 `sourceId`。
